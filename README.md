# Insider Clusters

Static site that lists U.S. public companies where two or more insiders bought shares on the open market (SEC Form 4, transaction code P), rebuilt daily.

Live: https://insider-clusters.netlify.app

**Data from public SEC Form 4 filings. For information only, not investment advice. Created by Caleb Love.**

- `build.py` pulls the market-wide insider-buy summary from the free MCP endpoint of the [SEC EDGAR Insider Trading API](https://rapidapi.com/KidriahChannel/api/sec-edgar-insider-trading-financials-api), which scans EDGAR under SEC fair-access rules, and writes `out/site/` (hub, one page per cluster buy, daily archive, methodology, RSS, sitemap).
- `data/history/` keeps one JSON snapshot per day for the archive.
- `ci/daily.yml` is the daily GitHub Actions rebuild and Netlify deploy.

Pages and summaries are generated by software from the filings. Filings can be amended and parsing can be wrong, so always check the linked filing. Not affiliated with the SEC.

Run it: `python3 build.py --site-url https://insider-clusters.netlify.app`
